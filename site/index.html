omachat

A self-hostable chat and voice platform, built around a native desktop client and a local daemon.

What it does

omachat combines a Qt client, command-line tools, realtime voice, and a server you can run yourself. Its daemon exposes a documented same-user IPC contract for local tools and integrations.

The ombrella checkout retains the standalone project and adds documented integration seams. The identity directions are proposals; no canonical mark has been selected.
